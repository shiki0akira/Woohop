# 倒放猜猜看——設計文件

> 狀態：**已上線，8 種語言**（2026-10-23）。
> 派對房間版（多支手機同步、音檔走伺服器、可計分）**等派對房間做好再做**。

## 一、遊戲簡介

出題的人錄一句話，手機把聲音倒過來播。大家學著唸那串怪聲，再倒回來聽，猜猜原本說什麼。大家輪流出題。

**適合人數：2～20 人。準備：一支手機就能玩，4 人以上可以各自用手機搶答。不計分**（暖場版，2026-10-23 使用者決定）。

## 二、規則定案（2026-10-23 使用者確認）

### 2.1 開場：幾個人、玩幾題、怎麼猜（2026-10-23 使用者改）

- **幾個人**（2～20，預設 6）旁邊並排**每人出幾題**（1 題／2 題／不限）。題數 = 人數 × 每人題數，進度條顯示第幾題；不限題數多一顆「結束遊戲」。
- **怎麼猜**：輪流猜（一支手機傳）或搶答（大家掃 QR code 打開「只有錄音機」`#rec`，各自學、各自倒放）。3 人以下不顯示、固定輪流猜。QR code 只在開場給，開始之後不再出現。
- **預設跟著人數換**（人數一變就套回預設）：3 人以下不限題數＋輪流猜；4～5 人每人兩題＋搶答；6 人以上每人一題＋搶答。
- 大家輪流出題（不是猜中的人出題），照著念會說「輪到第 n 個人出題」。

### 2.2 抽題

- 翻牌照抽卡取名的樣子（一疊卡 →「抽題目」→ 翻出題目 →「蓋起來，開始錄」）。題型由卡片決定，**不放選單**（主持人要好帶）：造句 75%（題庫給一個詞）、哼歌 15%（不指定歌名，避開版權）、自由發揮 10%。
- 「換一題」**一定換成另一種題型**。
- 錄完一定蓋著。猜不出來按「看提示」：造句是那個詞，哼歌／自由發揮是題型。「公布答案」放原聲。

### 2.3 錄音

- 最長 15 秒，頭尾安靜的部分自動剪掉，降噪／回音消除關掉（才錄得到別支手機喇叭的聲音）。兩個都固定，不給選項。
- 播放鍵播放中變「停止」，點了就停、播完變回來。錄音只在記憶體，不上傳。

### 2.4 一題分四段，一次只露一段

抽題目 → 翻開看題目（「蓋起來，開始錄」在左、「換一題」在右，按下去直接開始錄）→ 錄音（題卡縮成一行，錄音鍵在同一個畫面）→ 放倒放、大家學、猜不出來看提示、公布答案 → 下一題。每換一段捲回照著念；「下一題」在最後、不黏底，**公布答案之後才能按**。

## 三、評估過但決定不做

- **預先錄好倒放音檔的題庫**：8 語錄音成本高、題目會被玩完，歌曲還有版權。改成文字題庫＋玩家自己錄。
- **計分**：暖場版不計分，搶答本身就有勝負感。
