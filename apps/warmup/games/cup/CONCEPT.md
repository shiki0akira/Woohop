# 福杯滿溢（cup）

狀態：**已上線（2026-11-10，8 語）**。繁中版 2026-11-09 做完給老闆試玩，確認後補齊其他 7 語、接上首頁。

一支手機傳著玩：輪流往同一個杯子裡加水，誰讓水溢出來就輸。名字取自詩篇 23「我的福杯滿溢」——
玩的時候每個人都想「只加一點點」，但杯子的福氣是會滿的。

結構上跟定時炸彈是同一種遊戲（一支手機傳著玩、炸在誰手上誰輸），所以能照抄的就照抄：
輸家拉真心話大冒險拉霸、藏掉確切數字、音效用 Web Audio 當場合成。

## 一、玩法（老闆 2026-11-09 定案）

1. 大家圍一圈，手機交給第一個人（2～12 人，再多就分兩組）
2. 點一下「加水」開始加水、再點一次關水。**一個人加一次就換下一個人**
3. 手機傳給下一個人，一直輪下去
4. 水面會慢慢爬到杯口，然後**表面張力把水面撐成一個凸起**（鏡頭會自動拉近到杯口）——
   這時還沒溢出，小口小口加還能撐六到八次，但貪心一大口就當場輸
5. **誰讓水溢出來就輸**（傳統玩法，老闆在「加水最多的人贏」和這個之間選了這個）
6. 輸的人拉一下真心話大冒險拉霸

每一局的容器是從八種裡隨機抽的（2.10），其中三種看不到水位。

主持人可以準備實體道具（一個透明杯子和一壺水，手機開水的同時真的倒水），
沒道具就純用手機玩。**這件事只寫在玩法說明裡，不做成設定開關**（老闆要求）。

## 二、幾個自己決定的細節

### 2.1 不先輸入人數，直接傳著玩

開場只有一顆「開始遊戲」。畫面上只數「第幾個人加水」，不問一共幾個人。

理由：第一次玩的人預設就能玩（memory：web100-first-run-friction）。而且這個遊戲
**不需要知道人數**——不用排順序、不用算輪數、中途有人加入或離開也不影響。
先問人數只是多一道關卡，換來一個「第 3 輪第 2 個人」這種沒人在意的標籤。

代價：結束時只能說「這杯撐了 N 次加水」，不能說「撐了幾輪」。實測起來
「撐了 N 次」反而更好懂，因為每個人記得自己加過幾次。

### 2.2 加水速度：杯口以下越來越快，杯口以上是另一條曲線

**杯口以下**（水還在容器裡）：

```
d(水位)/dt = R0 × (1 + 1.6 × 水位)
```

空杯時最慢，到杯口時是最慢的 2.6 倍。這條曲線是**設計過的，不是對杯型做積分**，
八種容器共用。各杯型「水面升得快慢不一樣」是**形狀**造成的（見 2.10）。

**杯口以上**（表面張力撐住的那一段）規則完全不同。老闆 2026-11-09 實測舊版
「只要到表面張力，大概第三個人就會滿出來」——因為舊版在杯口以上還是沿用「越滿越快」，
剩下的空間最小、速度卻最快。但那一段正是整個遊戲最好玩的地方，不能一下子就過去。現在改成：

```
這一次加水推進的張力進度 = tenseK × （這一次開水幾秒）^1.6
```

1.6 次方是這個遊戲的賭注：**小口小口加可以撐很久，貪心一大口就當場輸**。
實測每次點 0.3 秒，張力段還能再加 6～8 次（點快一點 10～13 次）；
一口氣開著不放大約 1 秒就溢出來，溢得乾脆。tenseK 每種容器不同（0.78 燒杯最寬容 ～ 1.0 細頸瓶／保溫瓶最兇）。

### 2.3 杯子大小＝人數分段，上限 12 人

一直開著水不關，從空杯到**杯口**要：小杯 2.5 秒（2～5 人）、一般 4.5 秒（6～9 人）、大杯 6.5 秒（10～12 人）。
再多人就分兩組、兩支手機各玩一杯。

預設「一般」，三顆按鈕**固定顯示在開場、不收合**（老闆 2026-11-09：照人數選杯子是重要的一步，
收起來會被跳過）。按鈕上寫的是人數，因為杯子大小唯一要配合的就是人數。

取值的依據：一局的總次數 ≈（加到杯口的次數）＋（張力段 6～8 次）。張力段是固定成本，
所以杯子大小只調前半段。各段的**人數上限**算起來大約繞兩圈就有人輸；人少的時候圈數多一點，
但那時候一圈本來就很快，不會冷掉。

### 2.4 每次加水只有下限、沒有上限

- **下限 0.2 秒**：點一下就關也算 0.2 秒。沒有下限的話，每個人都可以加 0 秒傳下去，遊戲永遠不會結束
- **沒有上限**（老闆 2026-11-09）：想加多少是玩家自己的賭注。切到別的 App 或鎖屏會當場停水

### 2.5 表面張力那一段

- 水位 0～88%：水面在容器裡
- 水位 88～100%：**水面凸出杯口**，凸起高度隨水位長到 12～18px（每種容器不同），容器開始微微晃，
  流水聲變高、提示文字換成「水面已經凸起來了」，**鏡頭同時拉近到杯口**（見 2.11）
- 超過 100%：溢出

### 2.6 畫面上**沒有任何百分比**

杯子本身就是儀表板。跟定時炸彈藏掉倒數秒數同一個理由：給了數字，大家就會開始算，
而這個遊戲要的是「看著水面抖、不敢按」。只有「第幾個人加水」和結束後的「撐了幾次」是數字。

### 2.7 溢出之後只顯示「撐了幾次」

結束畫面只有一行數字：這杯撐了幾次加水。本來還有一行「水溢在第 N 個加水的人手上」，
**老闆 2026-11-09 劃掉了**——跟「撐了幾次」是同一個數字，而且輸的是誰現場都看得到。
同一場按「再來一杯」會留下**最多撐過幾次**當目標，但**不存進手機**（產品決定：不記上次玩過）。

### 2.8 沒有「結束遊戲」按鈕

遊戲自然結束在溢出那一刻。進行中手機在大家手上傳，擺一顆「結束遊戲」在那裡
只會被誤按；要中途收掉就按返回鍵（會先跳確認）。

### 2.9 音效三個，Web Audio 當場合成，不載音檔

- **加水**：循環的白噪音過 bandpass，**濾波頻率隨水位從 420Hz 爬到 1800Hz**
  ——倒水進容器時音高會變高，這是整個遊戲最重要的一個音
- **進入凸起**：一聲短短的高音提示，一場只響一次
- **溢出**：潑水聲（白噪音爆發＋低通往下掃）＋兩滴水聲

頂欄的音符鍵開關（`window.toggleMusic`），只有這個設定會記在手機裡。
**沒有背景配樂**：流水聲本身就是這個遊戲的配樂，跟定時炸彈的結論一樣。

### 2.10 八種容器，每一局隨機抽一種（老闆 2026-11-09）

「杯子大小」和「杯型」是兩件獨立的事：大小＝要幾秒才滿（配合人數），杯型＝長相與手感。

| 容器 | 透明 | 手感 | 抽中權重 |
|---|---|---|---|
| 高腳杯 | ✓ | 杯肚寬、杯口收起來，越接近杯口升得越快 | 1 |
| 直筒水杯 | ✓ | 上下一樣寬，水位線性，最好預測、最公平 | 1 |
| 細頸玻璃瓶 | ✓ | 瓶身寬瓶頸窄，水一進瓶頸就衝上去，那一段最刺激 | 1 |
| 量杯 | ✓ | 有刻度，最「可以算」的一款，可以約好不要超過哪條線 | 1 |
| 燒杯 | ✓ | 矮又寬，同樣的水量水位升得最慢，最寬容 | 1 |
| 陶壺 | ✗ | 看不到水位，壺口又小 | 0.6 |
| 馬克杯 | ✗ | 看不到水位，但杯口寬、早一點看得到水面 | 0.8 |
| 保溫瓶 | ✗ | 看不到水位**又**瓶口細，大魔王 | 0.6 |

水面高度是從每種容器的**剖面積出來的**，所以「瓶頸衝很快」「燒杯升得慢」都是形狀造成的，
沒有另外加速度參數。各段的凶狠程度另外用 `tenseK` 微調（2.2）。

**不透明的三種看不到水位，只有杯口看得到**（水撐到杯口那一刻會從壺口冒出來）。
一開始的設計是「聲音關掉就不抽不透明的」，老闆 2026-11-09 改掉：
不透明照樣抽得到，**而且正好是讓人想打開聲音的誘因**——開了聲音就能用流水聲的音高提早判斷。
聲音關著又抽到不透明時只給一句可以無視的提示，不擋路。三種合起來約佔三成。

### 2.11 水快滿的時候鏡頭拉近到杯口

老闆 2026-11-09：「實體最好玩的就是在杯口的表面張力。」凸起只有 12～18px，在手機上太小，
所以一進表面張力那一段就平滑拉近（0.5 秒），**溢出時維持拉近**（水漫出來要看清楚），
到結束畫面才回到原本大小。`prefers-reduced-motion` 時直接切換。

**倍率的上限是「這個杯型最寬的地方要整個留在畫面裡」**（1.25～2.05 倍，每種容器不同）。
老闆第一版回報「杯肚被切到了」就是超過這條線：杯身從畫面**下緣**出去像特寫，
左右一旦切到看起來就只是壞掉。要再放大就得接受杯身被裁，那是另一個取捨。

## 三、步驟頭放哪裡

`setup`、`rules`、`end` 放步驟頭（手機在主持人手上、主持人對大家說話）；
`play` 不放（手機在大家手上傳）。規則見 `apps/warmup/CLAUDE.md`。

## 四、各語言名稱（2026-11-09 老闆定案）

查過了：**這個玩法在各國都沒有既有的遊戲名字**。英文圈只有 "water cup challenge"／"Water Jenga"
這種描述性叫法（"Don't Spill It" 已經是一款英國桌遊），日本查到的是理科的「表面張力」和桌遊
「カッパ兄弟」，韓國沒有對應的酒桌遊戲。所以八種語言都是自己取，原則是**用當地人形容
「滿到杯緣」的那個說法**，不直譯（memory：localize-game-names-not-translate）。

| 語言 | 名稱 | 為什麼 |
|---|---|---|
| zh-TW | 福杯滿溢 | 詩篇 23 篇「我的福杯滿溢」。祝福 vs.「滿出來就輸」的反差好記，教會聚會那個客群一聽就懂。搜尋的關鍵字由副標（「一支手機輪流加水，誰讓水溢出來就輸」）扛，不靠遊戲名 |
| zh-CN | 水满则溢 | 「福杯满溢」在大陸不是共同語彙，改用成語；意思完全對，而且本身在講「貪心會翻車」 |
| en | One Drop Too Many | 沒有現成名字可借。直接講出輸的那一瞬間，比 "Water Cup Challenge" 有記憶點 |
| ja | なみなみチャレンジ | 「なみなみ」就是日文形容「滿到快溢出來」的詞 |
| ko | 찰랑찰랑 챌린지 | 「찰랑찰랑」是韓文形容水快滿、晃來晃去的擬態語 |
| de | Randvoll | 德文「滿到邊緣」一個字就講完 |
| fr | À ras bord | 法文慣用語「滿到杯緣」 |
| es | Hasta el borde | 西文慣用語，同上 |

zh-TW 與 zh-CN 刻意取不同名字：系列規則本來就是照當地說法取，不是同一串字轉簡繁。
