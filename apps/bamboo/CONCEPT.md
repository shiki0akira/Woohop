# 竹筍竹筍蹦蹦出——小組破冰遊戲設計文件

> 狀態：**zh-TW 版已上線**（2026-10-20，https://www.vibeweb100.com/bamboo/zh-TW/）。其他 7 種語言還沒做。程式在 app/，本機 `npm run dev`（launch.json 的 bamboo-dev，port 8791）。
> 這是第一個「不用手機的遊戲」。帶領播放器的共用部分（步驟教學、照著念、分享拉霸）會在這裡第一次做出來，之後上樓下樓、果園菜園動物園都會沿用。
> 系列整體架構在 `docs/ARCHITECTURE.md`，帶領播放器的構想在 `docs/redesign-plan.md` §5.1。

## 一、遊戲簡介

大家先蹲下來當竹筍，一起喊「竹筍竹筍蹦蹦出」之後，任何人都可以站起來喊下一個數字：1、2、3……。順序不能先講好，要看準時機。

兩個人同時站起來的話，要喊出**對方的名稱**，先喊出來的人站著，慢的人蹲回去。**最後一個還蹲著的人就輸了。**

名稱是開始前大家各自取的，可以是食物、飲料、動物、卡通角色，也可以直接用本名。撞到的時候喊「珍珠奶茶！」比喊本名好笑多了，所以手機最主要的工作就是**幫大家取名稱**。

**適合人數：4～20 人**（跟首頁 `site.js` 的設定一樣，2026-10-20 使用者把下限從 6 改成 4）。取名至少要 4 人才能開始（app.js 的 `MIN_PLAYERS`）。太多人的話，撞在一起的狀況會多到數不下去。
**時間：** 一輪 1～2 分鐘，包含取名大約 5 分鐘。
**準備：** 不用道具。手機只要一台，在主持人手上，取名時傳一圈。

## 二、規則定案

### 2.1 玩法

1. 每個人先取一個名稱（見 3.1）
2. 大家蹲下來，主持人帶著喊「竹筍竹筍蹦蹦出」
3. 任何人都可以站起來，照順序喊數字，從 1 開始。同一個人不能連續站兩次，因為站起來的人就不會再蹲下去了
4. **兩個人同時站起來**：要喊出對方的名稱
   - 先喊對的人站著，**他喊的數字算數**，下一個人接著喊下一個數字
   - 慢的人蹲回去，等下次再站起來
   - **兩個人同時喊出來**：猜拳，贏的人站著
   - **喊錯名稱**：不算，繼續喊，直到有人喊對為止
5. **最後一個還蹲著的人輸**。所以 N 個人會數到 N−1

**三個人以上同時站起來**：最先喊出任何一個人名稱的人留下，其他人都蹲回去。

### 2.2 手機不當裁判

手機不判斷誰先站起來、誰先喊，因為它看不到。**判定交給大家**，手機只負責取名、教學、配樂、分享拉霸。這是 redesign-plan §5.1 的原則：手機不介入遊戲本身。

## 三、手機做什麼

整體流程是：**選主題 → 取名 → 說明規則 → 玩 → 輸的人拉分享拉霸 → 再一輪**，每一步都是一個畫面（3.2）。

### 3.1 取名工具（這個遊戲最主要的功能）

**先決定主題，才開始抽。** 主題可以自己選，也可以按「隨機」，由手機挑一個主題。整局所有人都用同一個主題：

| 主題 | 效果 |
|---|---|
| 食物／飲料／動物／水果／甜點／卡通角色 | 大家從這個主題抽，或在這個主題下自己取 |
| 隨機（預設） | 手機隨機挑上面其中一個主題，畫面上會顯示挑到哪一個，不喜歡可以再按一次 |
| 用本名 | 不抽也不取名，撞到就喊對方的本名。**也不用設定人數**，按開始直接玩，數到幾由主持人帶（2026-10-20） |

「名人」主題不做，因為怕抽到政治人物或有爭議的人，改成「卡通角色」。

**每個人可以選自己取名，或抽一個：**

```
┌──────────────────────┐
│  第 3 位             │
│                      │
│   [ 抽一個 ]（大）    │
│   自己取…（小）       │
└──────────────────────┘
        ↓ 抽到
┌──────────────────────┐
│   你是……             │
│   🧋 珍珠奶茶（大字）  │
│                      │
│   [好，傳給下一個人]  │
│   換一個              │
└──────────────────────┘
```

- **不用先設定人數**：手機傳一圈，每個人取完按「傳給下一個人」，最後一個人按「大家都取好了，開始」。至少要 4 人才能開始
- **「用本名」例外**：不用傳手機、不用設定人數，直接到玩的畫面。沒有名稱表，也沒有「數到幾」的提示
- 「換一個」可以一直按，不限次數
- 自己取名稱的話，最多 8 個字。**跟已經有的名稱重複時，按鈕會停用**，並顯示「已經有人叫這個名字了」
- 抽的時候，同一局不會出現重複的名稱，也不會出現**聽起來很像的兩個名稱**（例如「奶茶」和「珍奶」）。名稱庫在資料檔裡會先分好組，同一組的只會抽到一個
- 全部取完會出現**全員名稱表**（大字格子），可以舉給大家看，記一下再開始。遊戲中隨時可以再打開

**名稱庫的原則：**
- 2～4 個字（外語是 1～3 個音節左右），喊得快的才好玩
- 每個主題每種語言至少 40 個，20 個人也夠抽，還有得換
- **每種語言各自準備當地熟悉的名稱，不是翻譯**。日文就放日本人熟悉的食物，不放「珍珠奶茶」的直譯
- 「卡通角色」只放各地大人小孩都認得的角色，喊得出來最重要

**這一局的名單存在 `sessionStorage`**（`web100-bamboo-game`）：不小心重新整理會接著玩，「再一輪」沿用；關掉分頁就沒了（產品決定：不記使用者玩過什麼）。主題和人數、音樂開關這些偏好存在 `localStorage`（`web100-bamboo-settings`）。

### 3.2 教學與照著念

- **整個遊戲就是一步一步帶**（2026-10-20 使用者要求）：不另外放教學投影片，每個畫面就是帶領的一步，主持人走到哪一步，畫面上就是那一步要做的事：
  1. 選一個主題 → 2. 大家取名（用本名時沒有這步）→ 3. 說明規則（三張插圖卡）→ 4. 開始！（口令、配樂）→ 5. 誰輸了？（拉霸）→ 回第 4 步再一輪
  - 每一步上方都有同一個步驟頭：步驟點、「STEP 3 / 5」、這一步的標題、「照著念」卡片（app.js 的 renderLead）
  - 第一頁的按鈕是「開始遊戲」，之後底部按鈕是「下一步：⋯」，只往前走
  - **返回鍵一律回到第一頁**（有名單先確認名單會清掉），不是回上一步（2026-10-20 使用者要求）
- 「照著念」提詞卡：主持人照著念就能把規則講完（第四節）

### 3.3 配樂（全部用 Web Audio 合成）

- **不放音檔**：沒有版權問題、不用下載，第一次載入後沒網路也能玩
- 按「開始這一輪」之後：
  1. 先放一小段**口令節奏**（鼓點，對著「竹—筍—竹—筍—蹦—蹦—出」七拍），主持人跟著喊
  2. 接著是**輕快、帶點懸念的背景音**，一直播到按「這輪結束」
- **要有音樂開關**，放在**遊戲頂欄**（一顆音符圖示，關掉時多一條斜線），**按了「開始遊戲」之後才出現**（選主題時還沒有配樂），記在手機上。做成全站共用頂欄的選用功能（chrome.mjs gameBar 的 `musicLabel`），之後有配樂的遊戲都能開（2026-10-20 使用者要求）。這點跟定時炸彈不一樣：主持人可能要講話，或場地需要安靜
- 玩的畫面**沒有「重新取名」**：按頂欄返回鍵就是回上一頁（有名單會先確認）
- `AudioContext` 在按「開始這一輪」的那一下建立，跟定時炸彈一樣，避開自動播放限制
- 鎖屏或切到背景時音樂停掉，回來不自動繼續，要再按一次

### 3.4 玩的時候的畫面

```
┌──────────────────────┐
│  竹筍竹筍蹦蹦出   ⚙   │
│                      │
│   ♪ 播放中            │
│                      │
│   [ 名稱表 ]          │
│   [ 這輪結束 ]（大）  │
└──────────────────────┘
```

- 手機不記數字、不記誰站了（2.2）
- **給主持人看的提示**：畫面上方小字寫「10 個人，數到 9 就結束」，人數是取名時算出來的（用本名時不顯示）
- **結束鍵是紅色、要按住 0.8 秒**：開始和結束是同一顆鍵，連點兩下或手滑就整輪沒了。按住時從左到右填滿，放開就退回去；鍵盤按 Enter 直接結束
- 「這輪結束」→ **分享拉霸**：輸的人拉一下，題目在窗格裡往上滾、越來越慢，停在哪一題就回答哪一題。這是把暖場變成認識彼此的關鍵（redesign-plan §5.1）。原本是設計系統的轉盤，使用者 2026-10-20 要求改成拉霸的感覺；拉霸還有一個好處：題目可以完整顯示，轉盤每格只放得下 4 個字
  - 拉霸裡有兩種：**真心話**（50 題問題）和**大冒險**（20 個簡單小動作，陌生人也做得出來、不用道具）。拉之前輸的人選「真心話／隨機／大冒險」，每輪重設回隨機，讓每個輸的人自己決定（2026-10-20 使用者要求）
  - 「再一輪」在拉霸卡片外面，不黏底（這頁比手機畫面高，黏著會蓋住「拉一下！」）
- 轉完 →「再一輪」（名稱不變）或「重新取名」

### 3.5 返回鍵

照系列規則：
- 教學、取名畫面：直接退出
- **取名取到一半**（已經有名稱了）：先跳確認，因為會白取
- 玩的時候：返回鍵先停音樂、回到「開始這一輪」的畫面，不跳確認，因為不會有東西不見（名稱都還在）
- 確認框開著時按返回鍵等於「繼續玩」。收尾**不要掛在 dialog 的 close 事件上**（跟定時炸彈一樣）
- 拉霸畫面按返回：回到玩的畫面

## 六、2026-10-20 確認過的決定

1. 三個人以上同時站起來：最先喊出任何一個人名稱的人留下，其他人蹲回去（2.1）
2. 「名人」改成「卡通角色」；另外有「用本名」，不用抽（3.1）
3. 不提供「跳過取名」，想省事就選「用本名」
4. 英文名稱用 Pop-Up Count
5. 畫面上顯示「N 個人，數到 N−1 就結束」，給主持人看（3.4）

## 七、評估過但決定不做

- **跳過取名、直接玩**：選「用本名」就夠了，不再多一個入口
- **隨機模式每抽一次換一個主題**：使用者要的是先有主題才抽，整局同一個主題
- **手機當裁判**（判斷誰先站起來）：做不到，而且會讓大家盯著手機，不是看彼此
- **每個人一支手機看自己的名稱**：要開房間，太麻煩，傳一圈就夠了
- **放音檔當配樂**：版權、檔案大小、離線都是問題，用合成的就好
