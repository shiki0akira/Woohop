# 果園菜園動物園——小組破冰遊戲設計文件

> 狀態：**開發中**（2026-10-21）。程式在 app/，本機 `npm run dev`（launch.json 的 orchard-dev，port 8793）。
> 跟竹筍竹筍蹦蹦出、上樓下樓同一套：不用手機的團康，手機只在主持人手上帶領。步驟頭、規則卡、拉霸、節拍器（含配樂）都是全站共用的 `window.Leader`（apps/homepage/assets/game.js）。

## 一、遊戲簡介

主持人出一個主題，例如「果園」，大家圍成一圈跟著拍子「拍、拍、蘋果」「拍、拍、香蕉」輪流接下去。說過的不能再說、不能說錯類別。

**適合人數：4～30 人**（不用在手機上設定人數，2026-10-21 使用者決定拿掉）。**時間：** 想玩多久都可以，主持人自己決定什麼時候結束。**準備：** 不用道具，主持人一支手機。

## 二、規則定案（2026-10-21 使用者確認）

### 2.1 節拍：三拍「拍、拍、說」
前兩拍大家一起拍手，第三拍輪到的人說一個符合主題的東西。節拍器三拍一組、第三拍是重拍；預設 90 BPM，自動加速預設開著。配樂跟拍子分開開關（跟上樓下樓一樣）。

### 2.2 主題：手機隨機抽，也可以自己選
前三個就是遊戲名稱的果園（水果）、菜園（蔬菜）、動物園（動物），再加便利商店、夜市、文具店⋯⋯各語言挑當地熟悉的。每次進「開始！」隨機抽一個；有人輸了按「換一個主題」，或從下面的清單自己選。「照著念」會跟著換成新主題。

### 2.3 怎樣算輸
1. **重複別人說過的**
2. **說錯類別**（動物園說了香蕉）
3. **卡太久**：不是一拍沒接上就輸，而是「真的卡太久」，由主持人判斷

誰輸由大家一起判斷，手機不當裁判。

### 2.4 輸了之後：換主題，從輸的人開始
遊戲不停下來，一直玩到主持人決定結束（按住「結束遊戲」），進到「誰輸了？」的真心話大冒險拉霸，誰要拉由主持人決定。

## 三、手機做什麼（一步一步帶）

1. **開場**：照著念＋開始遊戲（不用設定人數）
2. **說明規則**：三張插圖卡＋照著念
3. **開始**：主題卡（大字主題＋右上角的骰子鍵「換一個主題」）＋「自己選主題」（預設收起來，跟定時炸彈的自訂區間一樣）→ 節拍器 → 按住結束。主題不放開場：每次有人輸都要換，一定得留在這頁；開始頁靠縮版面變短（2026-10-22）
4. **誰輸了？**：真心話大冒險拉霸（配樂小聲當背景），「再玩一次」回第 3 步、重新抽主題
